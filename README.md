# String-function
Java implementations of string manipulation, pattern matching, and character-based algorithms.

A dedicated repository for exploring, practicing, and mastering built-in String methods and string manipulation techniques in Java.

## 📚 Topics Covered
* String Initialization & Memory Allocation (String Pool vs. Heap)
* Basic Operations (`length`, `charAt`, `concat`)
* Substring Extraction and Searching (`substring`, `indexOf`, `contains`)
* String Comparison (`equals`, `compareTo`, `equalsIgnoreCase`)
* Character Arrays and Type Conversion (`toCharArray`, `valueOf`)
* Immutability concepts and the `StringBuilder` / `StringBuffer` classes
* Regular Expressions and Splitting (`split`, `matches`)

## 🛠 Tech Stack
* Java
